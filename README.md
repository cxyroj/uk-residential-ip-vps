## 住宅IP和"原生IP"到底有什么区别

很多商家把"原生IP"和"住宅IP"混着卖，但这两者不是一回事。

原生IP(Native IP)指的是IP地理位置信息准确，比如一个显示为伦敦的IP，实际也确实是从英国机房分配出去的，而不是被平台识别出"IP库信息与实际服务器所在地不符"的那种。但原生IP依然可能属于数据中心ASN段，被大型风控平台标记为"Hosting/Datacenter"。
